# Notebook provenance

`pass-1.ipynb` through `pass-4.ipynb` are copied from the supplied public-workflow notebooks without code changes. `pass-5.ipynb` is copied from the supplied `pass-5-updated.ipynb` (v10.1.2 notebook source) and renamed for a consistent repository layout.

The notebooks are not guaranteed to run in an empty environment: they reference Kaggle input datasets, metadata datasets, and model/checkpoint artifacts by Kaggle paths. See the repository root README and `docs/reproducibility.md` before execution. Outputs have not been re-executed or regenerated as part of repository packaging.
